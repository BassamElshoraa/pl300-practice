## Reproduction

Run `npm run qa:all` and `npx tsc --noEmit`. The Edge regression script `scripts/presentation-browser-qa.mjs` accepts `QA_URL` and `QA_OFFLINE=true`; the offline mode blocks every nonlocal request.

Build with an empty base path for offline. Package using `node scripts/package-offline.mjs <new-folder>`, or `--refresh` only for a package previously generated by that script. GitHub Pages uses the existing deployment workflow and `/pl300-practice` base path.
