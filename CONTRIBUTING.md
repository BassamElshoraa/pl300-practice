# Contributing

Thanks for helping improve the PL-300 Practice Exam Simulator.

## Report a question or exhibit issue

Please include:

1. The mode and displayed question number.
2. The source label and source question number shown beside the question type.
3. What appears to be missing or incorrect.
4. A short explanation or an authoritative Microsoft Learn reference when available.

You can open a GitHub issue or contact [Bassam Elshoraa on LinkedIn](https://www.linkedin.com/in/bassam-elshoraa/).

## Propose a code change

1. Create a branch from `main`.
2. Keep changes focused and avoid modifying source question wording unless the correction is verified.
3. Run `npm run lint`, `npm run qa`, and `npm run build`.
4. Open a pull request describing the behavior before and after the change.

Do not commit generated folders such as `node_modules`, `dist`, `.next`, `.vinext`, or `.wrangler`.
