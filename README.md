A responsive, browser-based practice environment for the **Microsoft PL-300: Power BI Data Analyst** exam. It combines realistic timed mock exams, a complete source-question bank, visual answer areas, automatic scoring, detailed review, and beginner-friendly Egyptian Arabic explanations.

## Try it online

**Short GitHub Pages link:** [bassamelshoraa.github.io/pl300-practice](https://bassamelshoraa.github.io/pl300-practice/)

Core practice requires no registration. The learner name, active session, attempt history, progress analytics, and selected theme are stored locally in the browser. The optional connected AI Tutor uses a free learner account to protect the shared service from abuse.

## What is included

- **509 source questions** from the two owner-supplied collections; one empty vendor placeholder was excluded.
- **Four 50-question mock exams**, each with a 100-minute timer and balanced skill-area coverage.
- **Four non-overlapping bank parts** for working through the complete source collection.
- Single-choice, multiple-response, matching, hotspot, and visual answer-area interactions from the supplied bank. The interaction engine also supports ordering/drag-and-drop-style questions when future source items include them.
- **324 automatically graded questions** and **185 visual/manual-review questions**.
- Source exhibits and tables displayed with the questions that reference them.
- Question navigator, progress indicator, flags, unanswered-question warning, and resumable local progress.
- Learner-name setup with a saved local profile that can be renamed without losing progress.
- **Practice mode** with no timer and instant per-question feedback, plus **Exam mode** with timed, submission-only feedback.
- A question-aware **AI Tutor** in Practice mode: Egyptian-Arabic explanations, hints without answer leakage before Check Answer, follow-up chat, and exhibit vision when available.
- A local **My progress** center with attempt history, best and average score, time spent, and combined domain performance.
- **Custom practice** generated by skill area, topic, question count, feedback mode, and optional visual-question inclusion.
- Persistent **Bookmarks** with search and focused saved-question practice.
- A **My Mistakes** mastery loop: Needs review → Improving → Mastered after two consecutive correct answers.
- Deterministic classification of all 509 questions across **16 topics**, with topic-level analytics in results and progress history.
- **Backup & Restore** for exporting all local learner data and safely merging or replacing it on another browser or device.
- A monthly **PDF Library** with 12 unique owner-supplied files from January–August 2026; two byte-for-byte duplicate copies are excluded.
- A versioned **What’s New** dialog that opens once per release and remains available from every page footer.
- One-click Home/brand exit and browser Back handling that safely ends the active attempt.
- Final score, domain- and topic-level performance, correct-answer review, source explanations, and an expandable answer-key check for every option.
- **“شعبولي الدنيا”**: expanded explanations in beginner-friendly Egyptian Arabic, generated by the connected AI when available with a rich built-in fallback.
- A full Arabic/English interface and usage guide with RTL/LTR switching, light/dark themes, responsive layouts, keyboard-friendly controls, and Cairo typography. Original question text remains English and uses LTR layout in either interface language.

## Practice structure

| Session         |    Questions | Practice mode             | Exam mode                                         |
| --------------- | -----------: | ------------------------- | ------------------------------------------------- |
| Mock 01–04      |      50 each | Untimed, instant feedback | 100 minutes, feedback after submission            |
| Bank Part 01–04 | 127–128 each | Untimed, instant feedback | 2 minutes per question, feedback after submission |

The mock-exam builder targets the four PL-300 skill areas used by the simulator:

- Prepare the data — 28%
- Model the data — 26%
- Visualize and analyze the data — 26%
- Manage and secure Power BI — 20%

## Question interaction model

Every question displays a short instruction line before the prompt:

- **Single choice:** choose exactly one option.
- **Multiple response:** select every correct option.
- **Matching:** select one matching value for each row.
- **Sequence:** add every required step, then reorder it with the arrow controls.
- **Visual answer area / hotspot:** click the requested position or positions inside the source image; numbered markers preserve the selection order.

Visual items are separated from automatically graded items because their answers are image-based. The review screen shows the source answer image for direct comparison.

```bash
npm run dev
```

## Optional connected AI Tutor

Without configuration, the tutor runs as a deterministic local preview so the full interface and answer-gating behavior can be reviewed without accounts or API keys. To enable real conversational AI:

1. Create a Supabase project with Email/Password authentication.
2. Follow [`ai-tutor-worker/README.md`](ai-tutor-worker/README.md) to configure and deploy the Cloudflare Worker.
3. Copy `.env.example` to `.env.local`, replace the Worker URL, then rebuild the static site.

The answer key and official answer image are never sent to the AI before the learner presses **Check Answer**. The Worker stores no chat transcript.

## GitHub Pages deployment

Publishing is automated by [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml). A push to `main` builds the static site with the `/pl300-practice/` base path and deploys `dist/client` to GitHub Pages.

Repository settings required by GitHub: **Settings → Pages → Source → GitHub Actions**.
