# PL-300 Practice Lab

A browser-based PL-300 practice simulator built from the two owner-supplied question collections.

## Included

- 509 real source questions (one empty vendor placeholder excluded)
- Four 50-question exam simulations plus four non-overlapping full-bank practice parts
- Two minutes per question
- 324 text or structured questions with automatic grading
- 185 visual, hotspot, and ordering items with clickable answer images and source answers for manual review
- Question navigator, flags, unanswered-question warning, and progress saving
- Domain-level score report and answer review with explanations
- Responsive layout and light/dark themes
- Static export suitable for GitHub Pages

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

The project uses a static export so it can be adapted for GitHub Pages deployment in the publishing step.

## Content note

The question text, choices, answer keys, explanations, and visual answer areas are extracted from the two files supplied by the collection owner. Microsoft is not affiliated with or endorsing this practice resource.
